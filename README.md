# Mohamed Ashraf Fahmy — Portfolio

Static portfolio built with HTML, CSS, JavaScript, GSAP, ScrollTrigger, and Lenis. Includes four project case studies, a resume, scroll animations, and optional background audio.

## Run locally

From the project directory:

```powershell
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). No package installation or build step is required.

## Files

- `index.html`: portfolio sections and project links.
- `style.css` and `fonts.css`: layout, animation styles, and embedded fonts.
- `main.js`: scrolling, animation, audio, and case study viewer.
- `vendor/`: GSAP and ScrollTrigger scripts with their license notices.
- `work/`: MentoraX, LigoFlow, DawaBack, and TolabExam case studies and WebP screenshots.
- `resume/Resume.html`: resume.
- `audio/interactive-playground.mp3`: background audio.

## Hosting

Serve this directory as a static website. Use the repository root as the source directory for GitHub Pages; no build command is needed.
