The problem

Mentorax brings three services under one product: outsourcing and dedicated engineering teams, consulting and AI automation, and training with certification. Companies and individual learners both use it, so one codebase has to serve two very different kinds of customer, in more than one language.

What I built

  • Training and certification flows for courses, exam bookings and corporate packages.
  • Payments through the MAIB gateway, covering both individual purchases and company packages.
  • Multi-language interface (i18n) so content and checkout work for users in different markets.
  • Real-time features with Socket.io alongside the Django backend.
  • Day-to-day product work: new UI pages, backend API integration, feature updates and bug fixes across several active products.

Technical choices

  • Django and PostgreSQL carry the core data: users, bookings, packages and orders.
  • Redis handles caching and background work, so slower tasks stay off the request path.
  • Docker keeps local and deployed environments the same.
  • Bootstrap 5 keeps the interface consistent and quick to extend across pages.
