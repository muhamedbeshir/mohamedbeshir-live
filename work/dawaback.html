The problem

Pharmacies often hold stock that will expire before it sells, while another pharmacy nearby may need exactly that item. Dawaback lets pharmacists exchange near-expiry medicines, list a pharmacy for sale, and run targeted advertising for pharma products, which reduces medical waste.

What I built

  • Exchange marketplace where pharmacists list and find near-expiry medicines.
  • Pharmacy listings for sale, with their own listing flow.
  • Targeted pharma ads aimed at the right buyers.
  • Live updates over Socket.io, so listings and messages show up without a refresh.
  • Fast client state with Zustand and a Tailwind CSS interface.

Technical choices

  • React with Zustand keeps state small and predictable, without the weight of a larger store.
  • Supabase and PostgreSQL provide the database, auth and storage, which suited a short delivery window.
  • A Node.js API sits between the UI and the data for business rules.
  • Socket.io powers real-time updates where timing matters.
